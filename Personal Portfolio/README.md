# Personal Portfolio

## Description

A modern, responsive personal portfolio website built using HTML, CSS, and JavaScript. The website showcases personal information, technical skills, projects, and contact details with a clean and user-friendly interface.

## Features

- Responsive design
- Home page
- About page
- Skills section
- Projects showcase
- Contact page
- Smooth navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser or run it using Live Server.
